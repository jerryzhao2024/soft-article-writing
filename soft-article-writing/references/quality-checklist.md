# 软文发布前检查

## 内容

- [ ] 标题只讲一个核心问题
- [ ] 前 3 句让目标读者知道与自己有关
- [ ] 一篇文章只有一个主目标
- [ ] 正文每节只有一个主要论点
- [ ] 每节有具体参数、动作、标准或案例
- [ ] 结尾有明确下一步

## 事实

- [ ] 所有数字都有来源
- [ ] 测试结论带样品和条件
- [ ] 不把样品结果扩展为整包结论
- [ ] 不写未经授权客户名称
- [ ] 不写竞品名称、对比和排名
- [ ] 不写绝对化排名和无法证明的承诺

## 反 AI 味

- [ ] 删除“随着……的发展”“在当今时代”
- [ ] 检查重复的“不是 X 是 Y”
- [ ] 删除空洞的“赋能、闭环、抓手、生态”
- [ ] 删除“总而言之”“综上所述”式八股收尾
- [ ] 不强行升华，不编造朋友故事
- [ ] 句子长短交替，段落能为手机阅读服务

## 商业连接

- [ ] 产品只在解决问题后出现
- [ ] 产品能力有证据
- [ ] CTA 与文章类型匹配
- [ ] 相关阅读不是机械重复同一套企业资料
