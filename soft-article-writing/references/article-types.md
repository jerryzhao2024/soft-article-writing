# 软文类型与结构

## 1. 故障/痛点解释

适合：磨损、干涉、折弯、停机、信号异常、维护困难。

结构：

1. 现场现象
2. 常见误判
3. 真正原因
4. 检查顺序
5. 处理方式
6. 下一步

## 2. 选型清单

适合：机器人管线包、零部件、工业设备。

结构：

1. 选型为什么容易错
2. 必确认的 5–7 项
3. 每项的判断标准
4. 常见遗漏
5. 如何做试装
6. 获取检查表

## 3. 标准解读

适合：GB/T、ISO、团体标准、检测报告。

结构：

1. 一个常见误读
2. 标准解决什么问题
3. 测试条件和边界
4. 对采购的实际意义
5. 不能从标准直接推出的结论
6. 标准资料或技术沟通

## 4. 材料或结构对比

不点竞品，只比材料、结构或工况。

结构：

1. 对比对象
2. 不同材料的边界
3. 不同结构适用场景
4. 选择决策树
5. 验证方法
6. 咨询选型

## 5. 项目复盘

适合：改造、定制、交付、试装。

结构：

1. 项目背景
2. 初始问题
3. 现场数据
4. 方案变化
5. 试装与验收
6. 可复用经验

## 6. 产品机制说明

适合：48 系列、弹簧结构、旋转支架、波纹管、专用料号。

结构：

1. 它解决什么工况
2. 结构如何工作
3. 参数边界
4. 适配确认
5. BOM 与交付
6. 提交型号获取方案

## 7. 行业趋势

适合：装机量、国产替代、标准化、自动化升级。

结构：

1. 一个公开数据
2. 数据不能说明什么
3. 行业正在发生的变化
4. 对企业选型的影响
5. 可执行判断
6. 相关产品或资料

## 8. 企业能力介绍

只在需要集中介绍公司时使用，不要每篇复用。

结构：

1. 服务对象
2. 解决什么问题
3. 技术与质量
4. 标准与检测
5. 交付与服务
6. 下一步
